中国医械标准库
================================================

这是一个给医疗器械从业者用的标准库技能。
跑一次，它就会去国家标准全文公开系统、器械标管中心、行标备案库，
把现行有效的国标（GB / GB-T / GB-Z）和行标（YY / YY-T / YY-Z）抓下来，
生成一个能离线检索的单文件网页，每条都带官方页面链接。

按 2026-11-24 那次实抓，一全套下来约 2,800 条：
  现行约 1,950 · 即将实施约 190 · 征求意见中约 660

这个压缩包里不带数据，第一次要自己拉一遍（这是有意的：
数据在官方站上，拉下来的才是当时最新的）。


一、怎么用（只有一步）
------------------------------------------------
【给 AI 助手用】分两步：

  第一步、装上：把这个文件夹（或路径）交给它，说
      "装一下这个技能"
   它读 SKILL.md 后会把文件夹复制进自己的技能目录。
   装一次就行，以后一直在。

  第二步、使用：装好之后说
      "更新标准库"
   它就会跑：python run.py
   自检环境 → 抓数据 → 生成页面，全程约 10 分钟（实测 9 分 41 秒）。

【自己动手】不装也能用，双击文件夹里的  启动.bat
  效果一样，只是环境检查换成了黑窗口里自动做。

第一次运行：
  · 电脑上要有 Python 3.8 以上（没有会提示去装）
  · 不需要装任何第三方组件，只用 Python 自带的库
  · 全程约 10 分钟，跑完自动打开页面


一之二、运行条件
------------------------------------------------
  · Python 3.8 以上（python.org 下载，
    安装时勾选 Add Python to PATH）
  · 能联网（拉数据用）
  · 浏览器（看页面用，系统自带的就行）

  不需要装任何第三方包。

  Windows 双击 启动.bat；Mac / Linux 用 python3 run.py。

以后再用：
  · 看页面：直接双击生成好的那个 html 文件，断网也能看
  · 更新数据：再双击 启动.bat（⚠ 是全量重拉，不是增量）
  · 已经拉过数据、只想重新生成页面：python run.py --build（几秒钟）


二、页面怎么用
------------------------------------------------
· 顶部搜索框：搜标准号、标准名、材料、用途（例如 YY 0033 / 胶原蛋白 / 试验方法）
· 命中的部分会标出来，两种颜色区分「命中的是标准号」还是「命中的是名称」
· 左栏按用途筛：产品要求 / 材料标准 / 试验方法
· 按材料种类筛：金属 / 高分子 / 陶瓷与无机 / 天然与生物源 / 其他
· 按状态筛：现行 / 即将实施 / 征求意见中
· 点标题打开官方页面看原文（这一步要联网）

条件可以叠加：比如「试验方法 + 金属」只看金属类的试验方法标准。


三、常见问题
------------------------------------------------
问：页面上的日期不动？
答：那是库里最新一份标准的发布日期，不是运行时间。
    官方没发新标准，日期就不会变——这正好说明数据新不新。

问：多久要更新一次？
答：官方没固定节奏，想更新就双击 启动.bat 重拉一遍，全量覆盖。

问：拉一次要多久？
答：实测 9 分 41 秒。分三段：目录库和行标历史约 1 分钟，
    征求意见约 4 分钟（297 条通知要逐条进详情页拆项），
    补每条标准的详情约 5 分钟（2,122 条逐条请求）。
    机器和网络不一样，10 分钟左右算正常。

问：拉到一半断了？
答：重新双击 启动.bat，会整体重来一遍（全量，不做断点续）。

问：能直接拷给别人吗？
答：文件夹拷过去，对方的 data 是空的，他自己要拉一次。
    只想给一个人看，把生成好的那个 html 单文件发给他就行，断网也能打开。

问：一定要联网吗？
答：拉数据要联网。看页面不用。

问：为什么只有国标和行标，没有团体标准？
答：只收国标和行标这两类，这也是官方年报的对账口径。
    加进团标，就没法跟官方数字对账了。


四、文件说明
------------------------------------------------
启动.bat                      ← 双击这个（全量拉取 + 出页面）
run.py                        ← 一条命令跑完全套
scripts\check_env.py          ← 自检：Python 版本、三个源能不能连、目录能不能写
scripts\fetch_all.py          ← 抓目录库、行标历史、征求意见
scripts\fetch_detail.py       ← 补每条标准的详情字段
scripts\build_page.py         ← 合并去重 + 生成页面
templates\page.html           ← 页面模板
data\                         ← 拉下来的数据放这里（初次为空，跑一次后出现）
中国医械标准库_<日期>.html     ← 跑完自动生成（单文件，断网可用）

数据来源：
  标管中心·标准目录库    https://app.nidc.org.cn/biaogzx/qxqwk.do
  全国标准信息平台·行标备案  https://hbba.sacinfo.org.cn
  标管中心·征求意见       https://app.nidc.org.cn/biaogzx/dataGkZqyj.do
